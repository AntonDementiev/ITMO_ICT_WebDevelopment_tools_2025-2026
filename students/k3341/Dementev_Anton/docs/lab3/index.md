# ЛР3 — Docker и очереди

## Цель

Упаковать FastAPI-приложение в Docker, интегрировать парсер данных и настроить асинхронную очередь задач через Celery + Redis.

## Подзадачи

1. **Docker** — Dockerfile для FastAPI и парсера, docker-compose для оркестрации.
2. **HTTP-вызов парсера** — эндпоинт в FastAPI, который вызывает отдельный сервис-парсер.
3. **Очередь Celery** — асинхронный вызов парсера через Celery + Redis, периодические задачи.

## Сервисы

| Сервис | Порт | Описание |
|--------|------|----------|
| db | 5435 | PostgreSQL 16 |
| web | 8000 | FastAPI (основное приложение) |
| parser | 8001 | Сервис-парсер (отдельное FastAPI) |
| redis | — | Брокер задач Celery |
| worker | — | Celery worker |
| beat | — | Celery beat (периодические задачи) |
