# ЛР1 — FastAPI: Платформа для поиска людей в команду

## Цель

Реализовать полноценное серверное приложение на FastAPI — веб-платформу, которая помогает людям находить партнёров для совместной работы над проектами.

## Функциональность

- **Профили пользователей** — регистрация, авторизация (JWT), редактирование профиля (навыки, опыт, bio).
- **Навыки (Skills)** — CRUD для навыков пользователя с указанием уровня.
- **Проекты** — создание, просмотр, фильтрация по статусу, управление.
- **Команды** — создание команд в рамках проекта, добавление/удаление участников с ролями.
- **Поиск** — поиск пользователей по навыкам и минимальному опыту.

## Стек

- Python 3.11+
- FastAPI + Uvicorn
- SQLModel (SQLAlchemy + Pydantic)
- PostgreSQL
- Alembic (миграции)
- JWT-аутентификация (python-jose + passlib/bcrypt)

## Запуск

```bash
cd Lr_1
cp .env.example .env
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Swagger UI: [http://localhost:8000/docs](http://localhost:8000/docs)
