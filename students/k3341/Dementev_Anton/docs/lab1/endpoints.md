# Эндпоинты API

## Аутентификация (`/auth`)

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/auth/register` | Регистрация нового пользователя |
| POST | `/auth/token` | Получение JWT-токена |
| GET | `/auth/me` | Профиль текущего пользователя |
| PATCH | `/auth/me` | Обновление профиля |
| PATCH | `/auth/me/password` | Смена пароля |
| GET | `/auth/users` | Список всех пользователей |

## Навыки (`/skills`)

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/skills/` | Добавить навык |
| GET | `/skills/` | Мои навыки |
| PATCH | `/skills/{id}` | Обновить навык |
| DELETE | `/skills/{id}` | Удалить навык |

## Проекты (`/projects`)

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/projects/` | Создать проект |
| GET | `/projects/` | Список проектов (фильтр по статусу) |
| GET | `/projects/{id}` | Детали проекта |
| PATCH | `/projects/{id}` | Обновить проект |
| DELETE | `/projects/{id}` | Удалить проект |

## Команды (`/teams`)

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/teams/` | Создать команду |
| GET | `/teams/` | Список команд |
| GET | `/teams/{id}` | Детали команды |
| PATCH | `/teams/{id}` | Обновить команду |
| DELETE | `/teams/{id}` | Удалить команду |
| POST | `/teams/{id}/members` | Добавить участника |
| GET | `/teams/{id}/members` | Список участников |
| DELETE | `/teams/{id}/members/{mid}` | Удалить участника |

## Поиск (`/search`)

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/search/users?skill=...&min_experience=...` | Поиск пользователей |
